# chukio

(WIP) Rust interpreter for fast development iteration.

## Goal

I want to make a Rust interpreter because I think a part of Rust lang's weak point is its compilation speed.
For now, I'm going to make this to run some easy computation program!
Try to understand the Rust mechanics well, not to pass everything to LLM.
